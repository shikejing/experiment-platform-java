# experiment-platform-java

实验分流与效果度量核心服务。实验频繁调整时，同一份输入的分流结果与统计结果在任何时刻都可复现。

## 运行与测试

```bash
mvn test          # 运行全部自动化测试
mvn spring-boot:run
```

## 核心语义

### 1. 版本化与发布

- 实验配置以**完整版本**为单位提交（`POST /api/experiments/publish`），每次发布生成单调递增的版本号，版本内容不可变。
- 分流结果只来自某个已提交的完整版本，不存在新旧配置的字段级混合：发布时整体校验（变体权重之和必须为 100、变体 key 不重复、salt 非空、层槽位合法且不冲突），任一校验失败则本次发布整体失败，**上一个可用版本继续服务**。
- 回滚（`POST /api/experiments/{key}/rollback/{version}`）以历史版本的完整配置生成新版本生效，同一输入的分配与当时完全一致；任意历史版本也可通过 `GET /api/experiments/{key}/versions/{version}/assign` 复现。

### 2. 确定性分流

分流为纯函数，不依赖运行时随机化、`hashCode` 或迭代顺序：

1. **全局兜底**：`SHA256("fallback:" + unitId)` 映射到 `[0,10000)` 槽位，落入兜底比例区间的单位被所有实验排除；
2. **互斥层槽位**：`SHA256("layer:" + layerKey + ":" + unitId)` 决定单位进入层内哪个实验的槽位区间；
3. **变体分配**：`SHA256(salt + ":" + experimentKey + ":" + unitId)` 映射到槽位，变体按 key 字典序排列后按权重（权重 × 100 槽位）占据连续区间。

同一单位在同一实验同一版本下，无论并发度、执行顺序或进程重启，都落到同一个变体。

### 3. 互斥层与全局兜底

- 同一互斥层内各实验的槽位区间在发布时校验**互不重叠**，因此同一单位不可能同时进入同层相互冲突的多个实验；冲突的发布请求被拒绝且不影响在线版本。
- 注册表读路径只读 `AtomicReference` 持有的**不可变全局快照**，写路径在锁内完成全部校验后一次性原子切换，配置分批下发过程中读者看到的始终是某一个完整快照，约束在任何时刻成立。
- 被兜底命中的单位不得进入任何实验（分流判定中兜底优先于一切）。

### 4. 曝光与指标口径（幂等）

- 曝光按 `(实验, 版本, 单位)` 去重，事件按 `eventId` 去重：重复上报、乱序到达、超时重试均只计一次。
- 每条上报都会对对应版本**重新执行确定性分流**，只有分流结果与上报变体一致才计入；未真正命中实验的上报不会计入任何变体。
- 指标事件不要求曝光先到（乱序安全），只要求该单位在该版本下确实命中所报变体。

### 5. 统计口径

`GET /api/stats/{experimentKey}?metric=xxx` 按当前版本各变体返回：

| 字段 | 口径 |
| --- | --- |
| `count` | 该变体去重后的曝光单位数 |
| `ratio` | 该变体曝光数 / 实验总曝光数；总曝光为 0 时为 `null` |
| `mean` | 该变体该指标上报值的算术平均；无样本或指标无数据时为 `null` |

分母为零、样本为空或字段缺失时一律返回 `null`，不产生 `NaN`/`Infinity` 等无意义数值。非法输入与未知实验抛出/返回包含具体实验与变体标识的错误信息，异常链路可定位。

### 6. 热更新与并发读写

- 读路径无锁，只读不可变快照，正在进行的读取不会看到半更新状态；
- 发布/回滚/兜底比例更新在写锁内先校验后原子切换，失败时旧配置继续服务；
- 事件聚合使用并发容器，高并发重复上报下去重与计数仍然正确（见 `ConcurrencyTest`）。

### 7. 耗时上界

- **单次分流：O(1)** —— 常数次 SHA-256 计算 + 一次哈希表查询，与实验总数、变体总数无关；
- **单次事件写入：O(1)** —— 哈希集合去重 + 哈希表预聚合更新；
- **单次统计查询：O(V)** —— V 为该实验的变体数，所有聚合已按 `(实验,版本,变体,指标)` 预聚合在哈希表中，无需全量扫描事件流；实验数量与指标维度增长不影响单次查询耗时。

## 配置项

### 实验配置（`POST /api/experiments/publish` 请求体）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `key` | string | 实验唯一标识，非空 |
| `layerKey` | string | 所属互斥层；空表示独占流量不参与互斥 |
| `layerStartSlot` / `layerEndSlot` | int | 层内槽位区间 `[start,end)`，`0 <= start < end <= 10000`，同层互不重叠 |
| `salt` | string | 哈希盐，版本内固定；改变 salt 即整体重洗牌 |
| `variants` | array | 变体列表，`{key, weight}`，weight 为正整数且总和必须为 100 |

### 全局兜底比例

`POST /api/experiments/fallback?permille=N`，`N ∈ [0,10000]`，表示万分之 N 的单位被兜底排除；越界值被拒绝且旧值继续生效。

## REST 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/experiments/publish` | 发布新版本，失败返回 400 且不影响在线版本 |
| POST | `/api/experiments/{key}/rollback/{version}` | 回滚到历史版本 |
| POST | `/api/experiments/fallback?permille=N` | 更新全局兜底比例 |
| GET | `/api/experiments/{key}/assign?unitId=` | 按当前版本分流 |
| GET | `/api/experiments/{key}/versions/{version}/assign?unitId=` | 按指定版本复现分流 |
| POST | `/api/events/exposure` | 曝光上报（幂等） |
| POST | `/api/events/metric` | 指标上报（幂等） |
| GET | `/api/stats/{experimentKey}?metric=` | 查询各变体统计 |
