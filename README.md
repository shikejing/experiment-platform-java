# 实验分流与效果度量平台（experiment-platform-java）

面向频繁调整实验场景的分流与效果度量核心能力。核心设计原则：**同一份输入的分流结果与统计结果在任何时刻都可复现**——分流只读取已提交的不可变版本快照，分配由确定性哈希决定，不依赖运行时随机数、迭代顺序或进程状态。

---

## 1. 分流语义

### 1.1 版本化与发布
- 实验配置分两态：**草稿（Draft）** 与 **已发布版本（ExperimentVersion）**。草稿编辑不影响线上。
- 每次发布生成一个版本号单调递增的**不可变版本**（版本快照含完整的变体、权重、盐值、互斥层配置）。
- 分流只允许引用已发布版本的完整快照，**不存在新旧配置的字段级混合**：一次分流中引用的所有实验配置来自同一个快照。
- **回滚**不产生新版本，而是把已发布指针重新指向某个历史不可变版本。由于历史版本不可变、且分桶只依赖（盐值, 单位 id），回滚后同一单位的分配与该版本历史时刻完全一致。

### 1.2 确定性分桶
- 分桶器 `Bucketer` 基于 **SHA-256**：对 `盐值 + "|" + unitId` 取摘要前 8 字节，对 10000（万分比）取模。
- 不使用 `Math.random()`、对象 `hashCode()` 或任何迭代顺序相关逻辑。同一单位在同一实验同一版本下，无论并发度、执行顺序、重启，都落到同一变体。
- 变体选择：变体按名称排序、权重按万分比铺满 [0,10000)，桶号落在哪个区间即命中哪个变体。分配比例贴合配置（20000 单位样本实测比例偏差 < 1.5%）。

### 1.3 互斥层与全局兜底
- **互斥层（Layer）**：配置了相同 `layerId` 的实验同层互斥。层内实验按实验 id 排序、权重区间互不重叠，每个单位在每层**至多命中一个实验**；层间相互独立，可同时命中。
- 层内流量可不铺满（权重和 < 10000），剩余桶位表示不命中该层任何实验。
- **独立实验**：未配置 `layerId` 的实验各自独占一个隐式层，可与其他实验共存。
- **全局兜底（Fallback）**：`fallbackSalt + unitId` 桶号小于 `fallbackRateBps` 的单位进入兜底，**不进入任何实验**。兜底在每层分流之前判定。
- 互斥与兜底约束在配置分批下发（发布/回滚）过程中始终成立：读取侧永远拿到某一完整快照。

### 1.4 曝光命中校验
上报（曝光/指标）必须真正命中实验才计数，校验顺序：
1. 字段完整性（eventId、unitId、experimentId、variantName 必填）；
2. 实验与变体存在于当前已发布版本；
3. **命中判定**：以分流记录为准；分流记录缺失时（曝光先于分流到达的乱序场景），按当前快照**确定性重算**；未命中或变体不一致 → 抛出 `AssignmentMismatchException`，**不计入任何变体**；
4. **幂等去重**：以客户端生成的 `eventId` 为幂等键，重复上报（乱序到达、超时重试）返回首次结果，只计数一次。

## 2. 统计口径

- 指标按 **(实验, 变体, 指标名)** 三维预聚合，写入为 O(1) 累加，查询直接读聚合索引，不扫描明细事件。
- 每个变体输出：
  - `count`：样本数（曝光次数）；
  - `proportion`：该变体样本数 / 该实验总样本数；总样本为 0 时返回 **0**（不产生 NaN）；
  - `mean`：值字段均值 = `valueSum / valueCount`；无携带值字段的样本时返回 **null**（不产生无意义数值）；
  - `valueCount`：携带非空 value 的样本数；`valueSum`：值字段合计。
- 空样本（无任何上报）：总样本 0，各变体（含从未上报的变体）返回 count=0、proportion=0、mean=null，保证结果结构完整。
- 异常（实验不存在、变体不存在、未命中、字段缺失）分别抛出 `ExperimentNotFoundException` / `VariantNotFoundException` / `AssignmentMismatchException` / `IllegalArgumentException`，响应体携带 `experimentId`、`variantId`、`unitId`、`expectedVariant`，可定位到具体实验与变体。

## 3. 配置项

### 实验配置（ExperimentConfig / 草稿）
| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `experimentId` | 实验唯一标识 | 必填，非空 |
| `name` | 实验名称 | 必填 |
| `layerId` | 互斥层 id | 为空表示独立实验 |
| `layerWeightBps` | 层内流量权重（万分比） | [0,10000]；互斥层实验必须 > 0；同层合计 ≤ 10000 |
| `salt` | 分桶盐值 | 为空时使用 experimentId；修改盐值会改变重分桶结果 |
| `variants` | 变体列表 | 非空；变体名不重复；权重 ∈ [0,10000]；**合计必须 = 10000** |

### 全局配置（GlobalConfig）
| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `fallbackRateBps` | 全局兜底比例（万分比） | [0,10000]，0 表示关闭兜底 |
| `fallbackSalt` | 兜底分桶盐值 | 默认 `global_fallback` |

### 校验与失败语义
- 草稿保存、发布、全局配置更新均做完整校验；**任何校验失败都在变更前抛出**，上一个可用快照继续服务。
- 发布/回滚通过 `AtomicReference` 整体替换不可变快照，正在进行的读取不会看到半更新状态。

## 4. 性能上界

设 L = 互斥层数，E = 实验总数，V = 单实验变体数，H ≤ L = 命中实验数。

| 操作 | 耗时上界 | 说明 |
| --- | --- | --- |
| 单次分流 | **O(L · log(E/L) + H · log V)** | 1 次兜底哈希 + 每层 1 次哈希 + 层内二分 + 命中后每实验 1 次哈希 + 变体二分。不随 E 全量扫描。实测 200 实验 / 20 层下单次分流平均约 40µs |
| 单次统计查询 | **O(V)** | 直接命中 (实验,指标) → 变体 聚合索引，不扫描明细事件。实测 50000 条明细下单次查询约 20µs |
| 发布/回滚 | O(E + V) | 仅写路径：构建快照与预分桶索引，低频操作 |

## 5. API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/experiments/draft` | 保存实验草稿 |
| POST | `/api/experiments/{id}/publish` | 发布草稿（生成新版本） |
| POST | `/api/experiments/{id}/rollback?version=n` | 回滚到历史版本 |
| GET | `/api/experiments/{id}/versions` | 版本列表 |
| GET | `/api/experiments/{id}` | 当前已发布版本 |
| GET | `/api/shunt?unitId=u` | 分流（返回各命中实验与变体） |
| POST | `/api/exposures` | 曝光/指标上报（eventId 幂等） |
| GET | `/api/stats/{id}?metric=click` | 变体计数/比例/均值 |
| POST | `/api/config/global` | 更新全局兜底配置 |
| GET | `/api/config/global` | 读取全局配置 |

## 6. 关键实现类

| 类 | 职责 |
| --- | --- |
| `engine.Bucketer` | SHA-256 确定性分桶 |
| `engine.ShuntEngine` | 不可变快照上的确定性分流（兜底 → 层 → 变体） |
| `engine.SnapshotFactory` | 发布时构建不可变快照与层/变体预分桶索引 |
| `service.ExperimentService` | 草稿校验、版本化发布、回滚 |
| `service.ExposureService` | 命中校验 + eventId 幂等去重 + 指标写入 |
| `service.StatsService` | 聚合索引查询与零值补齐 |
| `store.*` | 版本/草稿/快照/分流记录/幂等/聚合的内存存储实现 |

## 7. 测试覆盖

- `ShuntEngineTest`：同单位同版本结果一致、80/20 与 50/50 比例贴合、8 线程并发分流一致性、遍历顺序无关。
- `VersionRollbackTest`：版本不可变、回滚后分配与历史一致、回滚缺失版本拒绝、发布失败旧版本继续服务。
- `MutexLayerTest`：同层互斥（至多一个）、层间独立、独立实验可共存、全局兜底命中率、层流量未铺满。
- `ExposureServiceTest`：重复上报计数一次、乱序到达确定性重算、超时重试、未命中变体拒绝且不计數、未知实验/变体、字段缺失、指标维度独立。
- `StatsServiceTest`：计数/比例/均值可复现、空样本零值 + mean=null、缺值字段、未上报变体补齐。
- `ConfigHotUpdateTest`：发布失败旧快照服务、全局配置热更新原子性、非法配置拒绝、发布期间并发读取不出现半更新状态。
- `PerformanceBoundTest`：200 实验下单次分流 < 100µs、50000 条明细下统计查询 < 50µs。
- `ApiIntegrationTest`：HTTP 全链路（草稿→发布→分流→曝光→统计）、发布失败 400、回滚后分配一致。
